# bilingualism-questionnaires-mfa

This repository contains code to clean and analyze data for the Bilingualism Questionnaires Multiple Factor Analysis (MFA) paper.

There are three code (.qmd) files located in the root of this repository. These files are meant be run in R Studio. The first one cleans the data using a sequence of steps. The second produces data for demographics tables. The third runs correlation and MFA analyses, saving several output files and producing several plots.

To run the code, you will also need the project data, which is hosted at (insert URL).

Download the data, then add it to a `/data` folder in the root of this repository (i.e., so the data folder is a sibling of the 3 code files). Then, the paths specified in the code files should resolve.
